| Aspect            | **PCD**                             | **PLY**                         |
| ----------------- | ----------------------------------- | ------------------------------- |
| Full name         | Point Cloud Data                    | Polygon File Format             |
| Origin            | Designed by the PCL community       | Designed at Stanford            |
| Primary use       | Point clouds in PCL pipelines       | General 3D data exchange        |
| Typical extension | `.pcd`                              | `.ply`                          |
| Goal              | Point-cloud–centric                 | General 3D container            |
| Supports          | unordered or organized point clouds | vertices and faces              |
| storage           | ASCII,Binary,Built-in compression   | ASCII,Binary, None standardized |
